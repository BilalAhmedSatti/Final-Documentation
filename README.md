# Final-Documentation

Pakistan EMI / Digital Banking documentation site — KYC journeys **J1–J19**, Domain Learning (11 pillars + SRS), SBP audit readiness, and interactive workflows.

Standalone from [BilalAhmedSatti/Documentation](https://github.com/BilalAhmedSatti/Documentation).

## Sources

- [KYC Journey Map](https://kyc-journey-map.vercel.app/)
- CCOF 2025 · EMI Regulations 2023 · BPRD Circular 04 of 2023 · AML/CFT

## Run locally

```bash
npm start
```

Open **http://localhost:5180**
